# exp003 训练时长实验分析

> 本文记录真实实验结果。建议来源文档见 `docs/suggestions/exp003/exp003_training_plan_copilot.md`。

## 实验目的

验证 exp002 的 768 输入配方是否因为训练轮数不足而尚未达到稳定水平。exp003 只将训练轮数从 30 增加到 60，其他主要配置保持不变。

## 实验配置

| 项目 | 值 |
|---|---|
| 模型 | SegFormer MIT-B0 |
| 输入尺寸 | 768 x 768 |
| batch size | 2 |
| 优化器 | AdamW |
| learning rate | 6e-5 |
| weight decay | 0.01 |
| loss | CrossEntropy，Ignore=0 |
| 增强 | 水平翻转 |
| 训练轮数 | 60 |
| 数据划分 | 固定 train.csv / val.csv，5597 / 1399 |
| 设备 | AutoDL RTX 5090 |
| 训练耗时 | 205.63 分钟 |

## 结果

| 指标 | exp002 | exp003 | 变化 |
|---|---:|---:|---:|
| 最佳 epoch | 30 | 60 | +30 |
| 最佳验证 mIoU | 0.7625846557 | **0.7791120845** | **+0.0165274288** |
| 最后一轮 mIoU | 0.7625846557 | 0.7791120845 | +0.0165274288 |

exp003 第 60 轮刷新最佳验证 mIoU，且 8 个有效类别全部高于 exp002 最佳结果：

| ID | 类别 | exp002 | exp003 epoch 60 | 变化 |
|---:|---|---:|---:|---:|
| 1 | Background | 0.688586 | 0.715195 | +0.026610 |
| 2 | Building | 0.833414 | 0.844602 | +0.011188 |
| 3 | Road | 0.805473 | 0.818184 | +0.012712 |
| 4 | Water | 0.868591 | 0.878559 | +0.009968 |
| 5 | Barren | 0.543651 | 0.558752 | +0.015101 |
| 6 | Vegetation | 0.876153 | 0.882134 | +0.005982 |
| 7 | Agricultural | 0.757427 | 0.773922 | +0.016495 |
| 8 | Vehicle | 0.727384 | 0.761548 | +0.034164 |

预测 Ignore 比例在训练记录中始终为 0，评价口径没有发生变化。

## 趋势判断

- epoch 31-40 平均 mIoU：0.761664
- epoch 41-50 平均 mIoU：0.767149
- epoch 51-60 平均 mIoU：0.768928
- 第 60 轮仍然是最佳轮次。

训练存在单轮波动，但后半程均值总体抬升，且末轮大幅刷新历史最佳。因此，“30 epoch 训练不足”得到固定 validation 支持。

## 当前结论

1. exp003 保留为新的本地验证基准，后续实验至少以 60 epoch 为训练时长基线。
2. 不能据此推断 test_1 一定同比提升。此前 test_1 为 0.591572，随机 validation 与 test_1 存在较大差距；仍需提交后验证泛化效果。
3. 下一实验不再重复做无 scheduler 的 30 epoch。应在 exp003 配方基础上单独测试学习率调度，或者先做有明确依据的颜色/尺度增强，但不能同时改动多个主要变量。
4. 由于 Vehicle、Background、Agricultural 的收益较大，下一轮不应只针对 Barren 加权；先观察 scheduler 或增强对 8 类整体的影响。
