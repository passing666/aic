# 冲击 mIoU 0.72 的战略分析（GLM）

> GLM 撰写，2026-09-06。依据：exp001–003 全链路数据、两次官方提交校准（兑换率 1:1、差距常数 0.170）、inference-001、stressed v1、三联图复核。本文回答一个问题：**从 0.6087 到 0.72 的 11 个点从哪里来。**

## 一、先算账：现有路线图不够

校准公式：**test_1 ≈ val − 0.170**（两次提交验证，常数稳定）。

- 当前：val 0.779 − 0.170 = 0.609 ✓
- 现有路线图全部走完（scheduler + 吞吐 + 增强 + Dice + B2 + 长训，乐观估计 val 0.80–0.82）：test ≈ **0.63–0.65**。
- 距 0.72 还差 **7–9 个点**。

结论：只沿"提 val"走打不到 0.72。必须同时做两件事：**把 val 天花板抬高到 0.82–0.85，把 0.170 的差距压到 0.13 以下**。差距常数并非不可动摇——它只是在"同一配方、同分布训练"的两次提交里稳定；域级手段改的就是这个常数本身。

## 二、11 个点的来源分解（按牌面）

**判断：0.72 可达但不宽裕，需要 1、2、3 全部兑现，5 视规则放行与否补足最后 2–3 个点。**

## 三、修订后的主线（在现有路线图上叠加）

## 四、风险与红线

1. **单模型红线不动**：无集成、无外部数据；EMA 和翻转 TTA 是单模型内操作，合规；权重汤（不同 run 平均）建议也不碰，避免争议。
2. 遥感预训练权重必须学术公开可下载（附 license 到方案 PDF），闭源/商业 API 违规。
3. 伪标签在获得书面确认前**一行代码都不写**。
4. 新骨干训练不稳是最大技术风险——所以先做 10ep 快验，绝不裸押。
5. 复赛（test_2）分数不理想不要慌：那是校准点，不是终点；半决赛才是计分轮。
