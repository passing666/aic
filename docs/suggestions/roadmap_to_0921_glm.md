# 9.21 复赛前 15 天执行路线图（GLM 综合版）

> 本文是 GLM 综合自身建议（`docs/suggestions/exp003/exp003_review_and_next_steps_glm.md`）与 Copilot 建议（`docs/suggestions/exp003/exp003_training_plan_copilot.md`）后给出的执行决定，供团队拍板。制定日期：2026-09-06，复赛 9.21（test_2，1300 张，不计决赛分但需 Docker 复现 + 方案 PDF），半决赛 10.10 前（test_1+2+3 合并，**计分**）。

## 一、综合判断：两份建议已收敛，分歧只剩两处

| 议题 | GLM | Copilot | 本文决定 |
|---|---|---|---|
| 先 scheduler 还是先增强 | scheduler（best=末轮两次） | exp003 后下一轮加 scheduler（其第 5 节原话） | **先 scheduler**，两份建议实际一致 |
| batch/lr 修改 | 提议合并为吞吐修正 | 先 benchmark，不与 scheduler 同轮 | **先 benchmark，再作为独立"吞吐修正"步**，不与 scheduler 混 |

## 二、执行路线（按日期）

### 第 1 批：零训练诊断（9.6–9.8，GPU 空闲即可做，与 Docker 骨架并行）

| # | 动作 | 产出/判据 |
|---|---|---|
| 1 | 用 **exp003 checkpoint** 跑 `compare_inference.py`：768-resize / 1024 全图 / 768 滑窗（stride 384 与 512 两组）/ 水平+垂直翻转 TTA | 定提交用推理策略；重点看 Vehicle、Road 增幅 |
| 2 | 扩展 `stressed_validation.py`：hue 偏移、每通道增益、gamma、轻度模糊+噪声 | 找出真正敏感的扰动 → 作为 exp005 增强配方依据 |
| 3 | （若通道开放）旧 resize-768 管线提交 exp003 | 得 val→test 兑换率：+0.0165 兑现 >0.01 → 训练线优先；<0.005 → 域适应优先 |
| 4 | batch 吞吐 benchmark（bs 2/4/8/16 显存与每轮耗时，约 10 分钟） | 决定第 2 批是否切换 bs8 |

同时：**Docker 骨架开工**（基础镜像、requirements 版本 pin、一键 train/predict 脚本、README 复现说明）。

### 第 2 批：训练主链（9.8–9.13，严格单变量串行）

每步判据统一：val mIoU + 每类 IoU（重点 Vehicle/Road/Barren）+ 扩展版 stressed val；每步保留完整实验目录，不覆盖。

| 步骤 | 唯一变量 | 预计耗时* | 通过标准 |
|---|---|---|---|
| exp004 | warmup(2ep)+cosine，其余同 exp003 | ~3.5h | val ≥ 0.782（即至少吃掉剩余未收敛部分） |
| exp004b | 吞吐修正：bs8 + lr 线性放大(≈2.4e-4)，沿用 cosine | ~1.5h | val 相对 exp004 掉幅 <0.003 即通过，此后所有实验用此配方跑 |
| exp005 | 几何+颜色增强：随机缩放 0.5–1.25 + 裁剪 + 垂直翻转 + （依诊断 2 结果选定的颜色项） | ~2h | val 与 stressed val 双升 |
| exp006 | CE + Dice（荒地定向，三联图显示荒地被植被吞并，Dice 对症） | ~2h | Barren ≥0.58 且总 mIoU 不降 |
| exp007 | MIT-B2 骨干 | ~4h | val ≥ 前最好 +0.005 |

\* 以 benchmark 实测为准；任何一步失败（不达通过标准）就停在当前最好配方继续下一步，不返工重调。

### 第 3 批：冻结与复赛材料（9.14–9.18）

1. **组合长训**：第 2 批赢家配置合并，80–100 epoch + cosine（一次性合并，此时归因已不重要，要的是复赛最强单模型），~4h。
2. **推理管线冻结**：滑窗参数 + TTA + `check_submission.py` 全链路，产出 test_2 推理 SOP（只换输入目录）。
3. **Docker 从零复现演练**：在干净环境用官方流程跑通"数据→训练→推理→打包"。半决赛后官方会亲自复现，失败即取消成绩，这条的优先级等于训练本身。
4. **技术方案 PDF**：动机/方法/伪代码，直接引用各实验目录数据。

### 9.19–9.20：复赛提交

- 模型：第 3 批组合长训 best。
- 提交前自检清单全绿 + 记录 checkpoint 路径、推理参数、zip 哈希、提交时间。
- 9.21 后：按复赛反馈微调，全力备战 10.10 半决赛（计分轮，且是三子集合并，域鲁棒性权重最高）。

## 三、明确不做的事

1. 多模型集成（违规）；外部数据/闭源权重（违规）。
2. 继续无 scheduler 地堆 epoch（exp003 已证明边际递减）。
3. 用 test_1 反馈逐轮调参（无标签，只做这一次校准提交）。
4. MIT-B3/更大模型、复杂结构改动（复现风险与 15 天窗口不匹配，留给总决赛）。
5. 全量 6996 重训**暂缓到半决赛前**——复赛前仍需 val 做选型与止损。

## 四、给团队的拍板点

1. 是否接受 exp004b"吞吐修正"作为配方级合并变量（bs8+lr 放大一步走）——建议接受，否则后面每个实验多花一倍机时。
2. 提交预算确认：9.21 前最多 2 次（exp003 校准 + 复赛正式）。
3. 荒地方案预注册：exp006 用 CE+Dice；若 exp005 增强后 Barren 自行回升 ≥0.58，则 exp006 改为 B2 前置。
